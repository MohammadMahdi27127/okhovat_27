# اخوت

ریشهٔ وب‌سرور را روی پوشهٔ `dist/` بگذارید. هر مسیر یک پوشه با فایل
`index.html` دارد. فایل‌ها برای نصب در ریشهٔ دامنه تنظیم شده‌اند.
برای اجرای محلی:

```sh
python3 -m http.server 8080 --directory dist
```

ناوبری با لینک‌های معمولی HTML و History API کار می‌کند. فقط خانه عمومی
است. صفحه‌های اعضا مقصد درخواست‌شده را در لینک ورود نگه می‌دارند. تا زمان
اتصال پایگاه داده، ورود و بازیابی رمز غیرفعال است. مرورگر فقط ترجیح تم
و وضعیت نمایش پیام خوشامد را برای رابط عمومی ذخیره می‌کند.

کد بخش‌های اعضا در `src/community.js` برای مرحلهٔ اتصال به سرور نگهداری
می‌شود و جزو فایل‌های قابل سرو نیست. کنترل هویت، مجوزها، تعلیق، داده‌های
اعضا و ثبت فعالیت باید در سمت سرور به جداول اصلی وصل شوند. فایل‌های
`schema/` طرح پیشنهادی هستند. `server/bale_reminders.py` نیاز به داده‌های
واقعی، توکن محیطی و زمان‌بندی سمت سرور دارد.
