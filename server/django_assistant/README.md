# دستیار رشد اخوت
چت در `/chat/` هنگام ورود، سرویس همان دامنه را بررسی می‌کند. در میزبانی استاتیک، گزارش‌های خود حساب آزمایشی در همین مرورگر، احوال‌پرسی و راهنمای صفحات کار می‌کنند. دادهٔ ساختگی برای حلقه تولید نمی‌شود. گفتگو در حافظهٔ صفحه است.

## ادغام با safa27
پوشهٔ django_assistant را کنار core در پروژهٔ Django 5.2 قرار بده. در urls.py اصلی پس از import کردن include و path، این الگو را قبل از مسیرهای عمومی فرانت‌اند قرار بده:

```python
path("api/assistant/", include("django_assistant.urls")),
```

در reverse proxy مسیر /api/assistant/ و مسیر ورود واقعی را به Django و فایل‌های dist را به سرویس استاتیک هدایت کن. در تنظیمات Django، LOGIN_URL باید مسیر ورود واقعی اعضا باشد. بک‌اند از نشست، CSRF، User.ring و PersonalGrowthRecord موجود استفاده می‌کند. برای خود دستیار جدول یا migration تازه‌ای لازم نیست. فرم رشد اصلی باید رکوردها را در همین جدول ثبت کند. چت گزارش آزمایشی مرورگر را به حساب واقعی وارد نمی‌کند.

## مدل زبانی اختیاری
با اجرای Ollama در شبکهٔ داخلی سرور و نصب یک مدل چندزبانه، نام همان مدل نصب‌شده را در تنظیمات Django بده:
```python
ASSISTANT_OLLAMA_MODEL = "qwen2.5:7b"
ASSISTANT_OLLAMA_URL = "http://127.0.0.1:11434"
```
مدل موضوع، دامنه و بازهٔ سؤال را به JSON محدود تبدیل می‌کند. فقط پیام جاری به مدل محلی فرستاده می‌شود. محاسبه و متن عددی قطعی هستند. اگر مدل تنظیم نشده یا پاسخ ندهد، تشخیص عبارت‌های فارسی ادامه می‌یابد. این سرویس متن گفتگو را ذخیره نمی‌کند.

## معنای آمار
هفته از شنبه با ساعت تهران شروع می‌شود. «هفتهٔ قبل» یک هفتهٔ کامل است. «مقایسه» همین روزهای سپری‌شدهٔ هفتهٔ قبل را می‌سنجد. «حلقه» اعضای فعال حلقهٔ فعلی و «هم‌حلقه‌ای‌هایم» همان مجموعه به‌جز خود شخص است. جمع ورزش و مطالعه فقط از گزارش‌های ثبت‌شده می‌آید. روز بدون گزارش معادل فعالیت صفر نیست.
